Meet Buddy — an assistant that talks like a mate

A warm, informal Android assistant from Starry. Ask it to open apps, send texts, change the volume or remember your WiFi password — by voice or text. Most of it works with no setup at all.

What it does

Built to be useful before you configure anything.

Works with zero setup

Open apps, open links, send texts, change volume, toggle the torch, set alarms and remember facts — all handled on the phone with no API call at all.

Hands-free voice

Flip on hands-free and the mic keeps listening, so you never tap again. Buddy reads its replies out loud too.

Ten AI providers, one app

OpenAI, Anthropic, Gemini, OpenRouter, Groq, Mistral, DeepSeek, Together, a local Ollama, or any custom OpenAI-compatible endpoint.

It can't burn your key

A hard per-session budget, a response cache and one model call per request. When the cap is hit Buddy stops and tells you.

It asks before it's scary

Sending texts and running commands always pause for a friendly confirmation, and every action is written to an on-device audit log.

Hands-free phone control

Optional accessibility support lets Buddy tap, type and scroll on your behalf — only when you ask it to.

Install

About a minute, no Android Studio needed.

  1. Download the APK on your Android phone.
  2. Open it from your notifications or Downloads.
  3. Allow installing from this source when Android asks (Settings → Apps → Special access → Install unknown apps).
  4. Install and open Buddy.
  5. Try it with no setup: say or type open chrome, remember my wifi password is blue123, volume up or what time is it.
  6. Optional: add an AI key in the gear menu, and switch on accessibility if you want Buddy to tap and type for you.

Why might Android call it "harmful" or "unsafe"?

Android shows that warning for any app installed outside the Play Store — it isn't a virus scan result, it's a policy about the source. It is made worse when an app is signed with a throwaway debug key, which is what earlier Buddy test builds used.

Buddy 2.0.1 ships as a properly signed release build (minified, non-debuggable, signed with the Starry release key), asks for fewer permissions than before, and no longer requests QUERY_ALL_PACKAGES. If Play Protect still shows a prompt, choose Install anyway — or tap Details → Scan to run a fresh check.

Privacy

Your data stays on your phone unless you point Buddy at a provider.

Keys are encrypted

API keys live in Android's EncryptedSharedPreferences, backed by the hardware keystore. They're never bundled in the app.

Local-first by design

Most commands never leave the device. Only requests that genuinely need a model are sent, and only to the provider you chose.

No analytics, no tracking

No third-party SDKs, no telemetry, and cloud backups are disabled.

Untrusted screen text is filtered

If screen contents are ever shared with a model, prompt-injection patterns are stripped first.
